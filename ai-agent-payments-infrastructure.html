AI Agent 支付从概念走向基础设施：当机器开始真正付钱

Cloudflare 推出 AI 钱包、Visa 发布 Agentic Payments 报告、Coinbase 测算营收暴增 700%——机器支付不再是概念，而是正在被建设的基础设施。

鉴叔 · 2026年8月 · 约 5,400 字 · 阅读约 16 分钟

引言：支付，是 AI 从“会说话”走向“能办事”的关键门槛

AI 的发展有一条清晰的主线：从“理解语言”到“调用工具”，再到“自主执行任务”。但在所有这些能力中，有一个環节长期缺失：支付。

一个 AI Agent 如果只能生成内容、回答问题、整理数据，它本质上仍然是“助手”。只有当它能够自主判断成本、发起交易、完成结算时，它才真正从“助手”变成“经济参与者”。

而这正是近期行业发生的最重要变化：多个全球最大的基础设施公司同时开始为 AI Agent 构建支付能力。这不是偶然，而是因为多个条件同时成熟了。

一、Cloudflare AI 钱包：互联网基础设施巨头的“支付层”入场

8 月 5 日，Cloudflare 宣布推出 AI Agent 可编程钱包，支持稳定币微支付，使用 x402 协议。这不是一家加密创业公司的实验，而是全球最大的互联网基础设施提供商之一，正式将稳定币支付嵌入其平台能力。

Cloudflare 每天处理全球超过 20% 的互联网流量。当它开始为其平台上运行的数百万个 AI Agent 提供“支付能力”时，这意味着什么？

  • AI Agent 可以在执行任务时自动发起微支付——调用一次 API、购买一次算力、获取一次数据，都可以自动付费
  • 支付媒介是稳定币，不是传统银行转账，不需要账户、不需要 KYC、不需要等待结算
  • 底层协议是 x402，把支付逻辑直接嵌入 HTTP 请求流程，不需要额外的支付网关
Cloudflare 要的不是“做钱包”，而是稳定币作为支付工具的功能性。它对底层链的态度是工具性的、可替换的——重要的是支付能力本身，而不是底层链是哪一条。

这个动作的核心意义在于：AI Agent 支付不再是“加密圈的概念讨论”，而是被互联网基础设施巨头纳入了产品能力。当全球最大的 CDN 和边缘计算平台开始提供 AI 支付能力时，这个能力就不再是“可选”，而是正在变成“默认”。

二、x402 协议：不是“又一个支付工具”，而是一种新的支付范式

要理解 AI Agent 支付的技术底层，就必须理解 x402。

x402 的名字来自 HTTP 状态码 402（Payment Required）。这个状态码在 HTTP 标准中被预留了几十年，一直没有被实际使用。现在，x402 终于被激活了——不是用于人类支付，而是用于机器支付。

它的核心逻辑非常简单：

  • AI Agent 发起一个 HTTP 请求（比如调用一个 API）
  • 服务端返回 402 状态码，附带价格和收款地址
  • Agent 自动用稳定币完成支付
  • 服务端确认收款后返回数据

整个过程不需要人类介入，不需要账户体系，不需要支付网关。它把支付变成了互联网请求的一部分，就像 HTTPS 把加密变成了网页访问的默认能力一样。

这种范式的深层意义在于：它把支付从“一个独立的系统”变成“互联网请求的内嵌能力”。这意味着任何能发起 HTTP 请求的程序，都可以自动完成支付。而 AI Agent，恰好是最擅长发起 HTTP 请求的程序。

三、Visa Agentic Payments 报告：数据很冷，但判断很热

7 月下旬，Visa 联合 Artemis 发布了一份关于 Agentic Payments（机器支付）的研究报告。报告的数据很说明问题：

  • x402 协议累计流水超过 90% 是刷量与测试
  • 实际市场规模仅约 1500 万美元
  • 大部分交易集中在少数几个应用场景

但报告的结论却非常明确：Agentic Commerce 被视为“支付行业最大的增长机会”。

这种“数据很小、判断很大”的现象，在技术行业中很常见。回顾电子商务早期、移动支付早期，都是类似的特征：绝对规模很小，但行业判断非常明确。因为决定行业方向的，不是当前规模，而是底层基础设施是否已经就绪。

而现在的情况是：基础设施正在迅速就绪。Cloudflare 提供支付能力、Coinbase 提供 x402 支持、稳定币提供结算媒介、智能合约提供授权逻辑。当这些组件同时就位时，市场规模只是时间问题。

四、Coinbase 的测算：为什么钱包赛道突然变成“必争之地”

7 月 27 日，深潮TechFlow 报道了一个引人注目的测算：Coinbase 估算，如果 AI Agent 大规模使用钱包进行自动支付，平台营收最高可暴增 700%。

这个数字背后的逻辑很清晰：

  • 传统交易所的收入来源是“人类交易手续费”，单笔金额大但频次低
  • AI Agent 支付的特征是“每笔金额小但频次极高”——每次 API 调用可能只有几美分，但每天可能发生百万次
  • 如果钱包平台能从每笔微支付中抽取微小费用，总量效应会远超传统模式

这就是为什么钱包赛道突然变成了“必争之地”。过去，钱包只是用户管理资产的工具。现在，钱包正在变成 AI Agent 的“支付操作系统”——它不只是存钱，而是提供授权、预算控制、自动执行和审计轨迹的能力。

五、为什么是现在？四个条件同时成熟

AI Agent 支付的概念并不新。但为什么它在这个时间点突然从“概念”走向“基础设施”？因为四个条件同时成熟了。

第一，AI 模型能力足够强。当下的 AI Agent 不只是“会聊天”，而是具备了任务理解、工具调用、多步执行的能力。它们可以判断“这个服务值不值这个价”，并自动发起交易。

第二，链上钱包和稳定币足够成熟。稳定币提供了低摩擦、全天候、可编程的结算媒介。钱包提供了托管、授权和执行能力。两者结合，AI Agent 就具备了“自己付钱”的完整能力。

第三，支付需求已经扩展到“机器对机器”场景。今天的 AI 不只是“帮人做事”，而是开始“代人做事”。当 AI Agent 需要为人类购买服务、购买算力、购买数据、购买 API 调用时，它就必须具备支付能力。

第四，监管环境开始容纳。《GENIUS 法案》为稳定币提供了清晰框架，《CLARITY 法案》拟明确开源开发者免责。这意味着构建 AI 支付基础设施的法律风险正在降低。

六、不只是“帮人买东西”：Agentic Commerce 的真正含义

很多人仍然把 AI Agent 支付理解为“AI 帮你下单”。这种理解太浅了。真正的 Agentic Commerce，是一种全新的商业执行范式，包含三个核心变化：

第一，交易从“人工触发”转为“自动触发”。传统支付需要人点击“确认付款”。AI Agent 支付不需要这个环节。Agent 在执行任务时，可以根据预设规则自动完成支付。这就像开车过高速收费站，从“停车交钱”变成“ETC 自动扣费”。

第二，支付从“一次性动作”转为“持续执行”。人类支付通常是一次性的：买一个商品、订一个服务。但 AI Agent 可以持续执行支付：根据预算规则持续购买数据、算力、内容服务或基础设施资源。这种“流式支付”模式，是传统支付系统很难支持的。

第三，商业逻辑从“人脑判断”转为“协议执行”。规则、预算、权限、费用上限都可以被编码进智能合约。这意味着支付不只是“转账”，而是一套包含授权、执行、审计、反馈的可编程系统。

核心转变：支付从“人与服务之间的动作”，变成“机器与服务之间的协议”。这不是简单地把“购物流程”自动化，而是把整个“代理—授权—结算—反馈”的链条变成可编程系统。

七、这对哪些行业会产生结构性影响

AI Agent 支付一旦进入基础设施阶段，它会重构几个行业的边界。

行业传统模式AI Agent 支付后的变化
传统支付公司人工发起、卡组织清算机器发起、链上即时结算，卡组织可能被绕过
互联网平台提供内容/服务，赚广告费提供可调用服务，按调用收费，变成“支付场景”
交易所/钱包托管资产、撮合交易提供 AI Agent 的支付操作系统，按流量收费
SaaS/API 服务订阅制、按月收费按调用收费、按结果收费，价格更精细
金融机构存款/贷款/清算提供 AI Agent 的支付授权层和合规层

换句话说，AI Agent 支付不只是“支付行业的变化”，而是“互联网经济模型的变化”。当支付可以被程序化、微粒度化、自动化地完成时，整个互联网的商业逻辑都会被重写。

八、稳定币：AI Agent 支付的“结算层”

AI Agent 支付为什么必须依赖稳定币，而不是传统银行转账？原因很简单：

  • 速度：AI Agent 的操作是毫秒级的，传统银行结算是天级的。稳定币可以实现即时结算。
  • 可编程性：稳定币可以被嵌入智能合约，支持条件支付、授权支付、预算控制等逻辑。传统银行转账做不到这些。
  • 无账户体系：AI Agent 不是“人”，它无法开设银行账户。稳定币钱包是它唯一的“资产容器”。
  • 跨境能力：AI Agent 没有国籍、没有时区。稳定币的 24/7 全球性与它天然匹配。

因此，稳定币和 AI Agent 支付的关系不是“可选搭配”，而是“结构性绑定”。没有稳定币，AI Agent 的支付能力就无法真正落地。反过来，没有 AI Agent 作为应用入口，稳定币也很难从“支付工具”升级为“智能经济底层”。

当 AI 代理成为真正的经济主体，稳定币就不再只是“币”，而是“机器的资产和支付中枢”。

九、这条赛道的真正竞争点：谁先搭好支付闭环

如果把 AI Agent 支付看作一个新赛道，当前的竞争格局已经很清晰：

玩家布局动作核心能力

真正的竞争焦点不是“谁先做出一个 AI 钱包”，而是“谁先搭好完整的支付闭环”。这个闭环包括：钱包能力、授权能力、预算控制、合规能力、服务发现和结算能力。

谁能率先把这套能力完整地提供给开发者，谁就能成为 AI Agent 经济的“支付基础设施”。

十、结语：从“会说话”到“能付钱”，是 AI 真正进入经济系统的分水岭

回看 AI 的发展历程，每一次重大突破都伴随着一种“新能力”的获得：理解语言、生成内容、调用工具、多模态输入。而“支付”，可能是其中最具经济意义的一个能力跃迁。

因为一旦 AI Agent 能够自主完成支付，它就不再是“工具”，而是“经济参与者”。这个变化表面上是技术升级，实际上是整个互联网经济结构的重构。

如果说过去的互联网是“信息流”，那么下一阶段很可能是“指令流 + 价值流”同时运行。AI 负责理解和执行，区块链和稳定币负责结算和托管，支付协议负责把两者连接起来。

这个时代真正重要的，不再是“AI 能不能回答”，而是“AI 能不能真的替你完成一次真实的交易”。而现在，基础设施已经开始就绪。
