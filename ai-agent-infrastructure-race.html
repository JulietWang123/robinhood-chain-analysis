AI Agent 经济的基础设施竞赛：算力、支付、钱包三线并进

AI Agent 不只需要“会说话”，更需要“能付钱”和“能买算力”。围绕 Agent 经济的三层基础设施——算力层、支付层、应用层——正在同时被建设。

鉴叔 · 2026年8月 · 约 5,600 字 · 阅读约 17 分钟

引言：AI Agent 的“基础设施时刻”

过去两年，关于 AI 的讨论大多集中在“模型多强”——参数量、推理能力、多模态。但一个很少被认真讨论的问题是：当 AI 从“回答问题的工具”变成“自主执行任务的代理”时，它需要什么样的基础设施？

答案正在过去几周变得清晰。至少四件标志性事件同时发生，它们共同描绘了一幅 AI Agent 基础设施的完整版图：

  • Arthur Hayes 宣布创建去中心化算力网络 Flop Labs（8/20）
  • Stripe 收购 OpenRouter，称“为 AI 建设经济基础设施 = 为互联网建设经济基础设施”（8/20）
  • Cloudflare 推出 AI Agent 可编程钱包 + x402（8/5）
  • Coinbase 测算：AI Agent 支付可使钱包平台营收最高暴增 700%（7/27）

这四件事分别对应 AI Agent 经济的三层基础设施：算力层、支付层、应用层。它们不是孤立的，而是在回答同一个问题：AI Agent 要真正成为经济参与者，需要什么样的底层支撑。

一、为什么 AI Agent 需要自己的基础设施

要理解这场竞赛，先要理解一个根本问题：为什么 AI Agent 不能直接用现有的互联网基础设施？

因为现有的互联网基础设施是为“人”设计的，而不是为“机器”设计的。具体体现在三个层面：

  • 算力：人类使用云服务需要注册账号、绑定信用卡、签订合同。但 AI Agent 需要在毫秒间自主获取算力，无法走传统的人工注册流程
  • 支付：人类支付需要账户、银行卡、KYC。但 AI Agent 不是“人”，它无法开设银行账户，也无法通过 KYC
  • 应用：人类使用应用需要图形界面。但 AI Agent 需要可编程接口、可自动调用的服务
AI Agent 经济的核心矛盾是：机器已经具备了“自主决策”的能力，但现有的基础设施仍然要求“人类在环”。这个矛盾，正是三层新基础设施要解决的问题。

二、算力层：Arthur Hayes 与 Flop Labs 的去中心化算力网络

8 月 20 日，Arthur Hayes 宣布 Flop Labs 将创建去中心化算力网络，测试网参与者将获约 20% 代币供应。他提出的核心判断非常尖锐：AI 智能体没法自己买算力，去中心化算力网络将迎来机会。

这个判断背后的逻辑是：当 AI Agent 开始自主执行任务时，它需要大量算力。但传统云服务商（AWS、Google Cloud）的购买流程是为人设计的——需要企业账户、信用卡、合同。AI Agent 无法自主完成这些流程。

去中心化算力网络提供了一个可能的解决方案：AI Agent 可以用稳定币直接支付，无需人工注册，即可获取算力。这把“买算力”从“人类采购行为”变成了“机器自动行为”。

值得注意的是，Arthur Hayes 作为 BitMEX 联合创始人，他的入局本身就是一个信号：加密行业的资深玩家开始把 AI Agent 的“算力需求”看作一个独立的基础设施赛道。

三、支付层：Cloudflare AI 钱包与 x402 协议

8 月 5 日，Cloudflare 推出 AI Agent 可编程钱包，支持稳定币微支付，使用 x402 协议。作为处理全球超过 20% 互联网流量的基础设施巨头，Cloudflare 的入局意义重大。

x402 的名字来自 HTTP 状态码 402（Payment Required）。这个状态码在 HTTP 标准中被预留了几十年，一直没有被实际使用。现在，x402 终于被激活——不是用于人类支付，而是用于机器支付。

它的核心逻辑非常简单：

  • AI Agent 发起一个 HTTP 请求（比如调用一个 API）
  • 服务端返回 402 状态码，附带价格和收款地址
  • Agent 自动用稳定币完成支付
  • 服务端确认收款后返回数据

整个过程不需要人类介入，不需要账户体系，不需要支付网关。它把支付变成了互联网请求的一部分，就像 HTTPS 把加密变成了网页访问的默认能力一样。

Cloudflare 要的不是“做钱包”，而是稳定币作为支付工具的功能性。它对底层链的态度是工具性的、可替换的——重要的是支付能力本身，而不是底层链是哪一条。

四、应用层：Stripe 收购 OpenRouter 的战略思考

8 月 20 日，Stripe 致投资人信中称“奇点已经到来”，并宣布收购 OpenRouter。其核心观点非常直接：为互联网建设经济基础设施和为 AI 建设经济基础设施，基本上是同一件事。

OpenRouter 是一个聚合多个 AI 模型的路由平台，开发者可以通过它调用不同的 AI 模型。Stripe 收购它的战略意图很清晰：当 AI Agent 开始大规模调用模型服务时，每一次调用都需要支付。而 Stripe 正是支付基础设施的龙头。

这个收购揭示了一个重要趋势：支付巨头不再把自己定位为“交易处理商”，而是定位为“AI 经济的基础设施提供者”。Stripe 把 AI 模型调用（应用层）和支付（支付层）绑定在一起，形成了一个完整的“调用-付费”闭环。

五、Coinbase 的测算：为什么钱包变成“必争之地”

7 月 27 日，Coinbase 估算，如果 AI Agent 大规模使用钱包进行自动支付，平台营收最高可暴增 700%。这个数字揭示了钱包赛道为什么突然变成了交易所和稳定币巨头的必争之地。

这个数字背后的逻辑很清晰：

  • 传统交易所的收入来源是“人类交易手续费”，单笔金额大但频次低
  • AI Agent 支付的特征是“每笔金额小但频次极高”——每次 API 调用可能只有几美分，但每天可能发生百万次
  • 如果钱包平台能从每笔微支付中抽取微小费用，总量效应会远超传统模式

这就是为什么钱包赛道突然变成了“必争之地”。过去，钱包只是用户管理资产的工具。现在，钱包正在变成 AI Agent 的“支付操作系统”——它不只是存钱，而是提供授权、预算控制、自动执行和审计轨迹的能力。

六、三层基础设施的完整图景

把这四件事放在一起看，会发现它们构成了 AI Agent 经济的三层完整基础设施：

层级解决什么问题代表玩家核心技术
算力层AI Agent 如何自主获取算力Flop Labs（Arthur Hayes）去中心化算力网络 + 稳定币支付
支付层AI Agent 如何自主完成付款Cloudflare、Coinbasex402 协议 + 可编程钱包
应用层AI Agent 如何调用服务并付费Stripe、OpenRouter模型路由 + 支付 API

这三层不是孤立的，而是相互依赖的：

  • 算力层提供“能力”——让 AI Agent 能够执行任务
  • 支付层提供“手段”——让 AI Agent 能够为能力付费
  • 应用层提供“场景”——让 AI Agent 知道去哪里调用服务
三层基础设施同时被建设，说明 AI Agent 经济已经从“概念阶段”进入“基础设施建设阶段”。这是一个产业成熟的关键信号。

七、稳定币：三层基础设施的共同结算层

仔细观察会发现，这三层基础设施有一个共同的底层：稳定币。

无论是 Flop Labs 的算力支付、Cloudflare 的微支付，还是 Stripe 的模型调用付费，都需要一个结算媒介。而稳定币恰好是最适合 AI Agent 的结算媒介：

  • 速度：AI Agent 的操作是毫秒级的，传统银行结算是天级的。稳定币可以实现即时结算
  • 可编程性：稳定币可以被嵌入智能合约，支持条件支付、授权支付、预算控制
  • 无账户体系：AI Agent 无法开设银行账户，稳定币钱包是它唯一的“资产容器”
  • 跨境能力：AI Agent 没有国籍、没有时区。稳定币的 24/7 全球性与它天然匹配

这就是为什么稳定币和 AI Agent 两个叙事会迅速绑定。没有稳定币，AI Agent 的三层基础设施就缺少了共同的结算底层。

八、为什么是现在？四个条件同时成熟

AI Agent 基础设施竞赛在这个时间点集中爆发，是因为四个条件同时成熟了。

第一，模型能力足够强。当下的 AI Agent 不只是“会聊天”，而是具备了任务理解、工具调用、多步执行的能力。它们可以自主决策“需要什么资源”并发起购买。

第二，链上钱包和稳定币足够成熟。稳定币提供了低摩擦、全天候、可编程的结算媒介。钱包提供了托管、授权和执行能力。

第三，基础设施巨头全面入局。Cloudflare、Stripe、Coinbase 这些行业龙头同时下场，说明 AI Agent 支付已经不是“小众实验”，而是主流基础设施竞争。

第四，监管环境开始容纳。《GENIUS 法案》为稳定币提供了清晰框架，《CLARITY 法案》拟明确开源开发者免责。这意味着构建 AI 支付基础设施的法律风险正在降低。

九、一个重要的现实提醒：真实市场仍然很小

在看好 AI Agent 支付前景的同时，必须保持清醒：目前的真实市场仍然很小。

Visa 联合 Artemis 发布的 Agentic Payments 报告显示，x402 协议累计流水超过 90% 是刷量与测试，实际市场仅约 1500 万美元。这说明，AI Agent 支付仍然处于非常早期的阶段。

但这种“数据很小、判断很大”的现象，在技术行业中很常见。回顾电子商务早期、移动支付早期，都是类似的特征：绝对规模很小，但行业判断非常明确。因为决定行业方向的，不是当前规模，而是底层基础设施是否已经就绪。

而现在的情况是：三层基础设施正在迅速就绪。当算力层、支付层、应用层同时就位时，市场规模只是时间问题。

十、这对行业格局意味着什么

10.1 基础设施之争，而非应用之争

AI Agent 经济的竞争焦点，不是“谁先做出一个好用的 Agent”，而是“谁先搭好完整的基础设施堆栈”。这就像互联网早期，真正的赢家不是某个具体网站，而是 TCP/IP、HTTP、DNS 这些底层协议的构建者。

10.2 “机器支付”将重写互联网经济模型

当支付可以被程序化、微粒度化、自动化地完成时，整个互联网的商业逻辑都会被重写。从“免费试用 + 广告变现”转向“按调用付费 + 按结果付费”——这是一个根本性的商业模式变革。

10.3 稳定币从“支付工具”升级为“机器经济底层”

当 AI Agent 成为真正的经济主体时，稳定币就不再只是“币”，而是“机器的资产和支付中枢”。这意味着稳定币的应用场景从“人类支付”扩展到了“机器支付”，而后者的交易频次可能远超前者。

十一、结语：从“会说话”到“能办事”的分水岭

回看 AI 的发展历程，每一次重大突破都伴随着一种“新能力”的获得：理解语言、生成内容、调用工具、多模态输入。而“自主执行”——包括买算力、付费、调用服务——可能是其中最具经济意义的一步。

因为一旦 AI Agent 能够自主获取算力、自主完成支付、自主调用服务，它就不再是“工具”，而是“经济参与者”。而支撑这一切的，正是算力、支付、钱包三层基础设施。

Stripe 的判断值得反复品味：“为互联网建设经济基础设施和为 AI 建设经济基础设施，基本上是同一件事。”这句话揭示了一个深刻的真相：AI Agent 经济不是互联网的“额外功能”，而是互联网的“下一个形态”。

如果说过去的互联网是“信息流”，那么下一阶段很可能是“指令流 + 价值流”同时运行。AI 负责理解和执行，算力网络提供能力，稳定币和钱包负责结算和托管，支付协议把它们连接起来。

而现在，这三层基础设施正在同时被建设。这才是 AI Agent 经济真正值得关注的地方。
